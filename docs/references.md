# Reference methods and architectural inspiration

FluoInspect currently implements a development axial intensity-pattern screen
and descriptive supporting measurements. The papers below are reference methods
or architectural inspiration; their software and model weights are not bundled.

- [PathAgent](https://arxiv.org/abs/2511.17052): adaptive region investigation.
- [HarnessIR](https://arxiv.org/abs/2610.10133): evidence collection and separate verification roles.
- [BaSiC](https://www.nature.com/articles/ncomms14836): fluorescence shading and background models.
- [ASHLAR](https://pmc.ncbi.nlm.nih.gov/articles/PMC9525007/): overlap-based microscopy stitching and registration.
- [QUAREP-LiMi](https://quarep.org/working-groups/wg-3-field-homogeneity/): field-homogeneity measurement and reference protocols.

These sources do not establish FluoInspect detection performance. Optional future
integrations need their own dependency, license, input-format and validation review.
